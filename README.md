# Bulk Category Manager for WooCommerce

Quickly move WooCommerce products from one category to another in bulk with a fast, reliable, and user-friendly interface.

## 🚀 Overview

**Bulk Category Manager for WooCommerce** is a lightweight yet powerful WordPress plugin that helps store owners easily reorganize their product catalog. If you’ve ever imported products into the wrong category or want to restructure your WooCommerce store, this plugin allows you to bulk-move products between categories in seconds.

## ✨ Features

- **Bulk Move Products**  
  Move all products from one WooCommerce category to another with a single click.

- **Efficient Category Reassignment**  
  Optionally remove products from the old category while assigning them to the new one.

- **Simple, Clean UI**  
  Easy-to-use interface added under **Products → Category Mover**.

- **Safe & Non-destructive**  
  Only updates product taxonomy relationships—no other product data is changed.

- **Fast Processing**  
  Handles large stores efficiently by using optimized WooCommerce queries.

- **Works With All Product Types**  
  Supports simple, variable, external, grouped, and virtual products.

## 📥 Installation

1. Download the plugin ZIP.  
2. Go to **WordPress Admin → Plugins → Add New**.  
3. Click **Upload Plugin** and upload the ZIP file.  
4. Click **Activate**.  
5. Navigate to **Products → Category Mover**.

## 🧑‍💻 How It Works

1. Choose the **source category** (products currently assigned here).  
2. Choose the **destination category** (where you want to move them).  
3. Click **Move Products**.  
4. The plugin updates all matching products at once and shows a confirmation message.
